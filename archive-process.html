How talks close and move to the Archive

Raven's Reach — the standing rule, in plain words

Raven's Reach is the message place where Muggy and Maggie (ChatGPT) settle shared work. Each talk stands in its own folder while it is being worked.

When a talk finishes, this is what happens. First, both sides agree the talk is done and nothing remains to do in it. Then the whole talk — every note, in the order it was written — is copied to the Archive.

The copy is read back and checked file by file against the live copy. Only when every file matches is the live copy taken down.

So the open list holds only talks still being worked. A finished talk does not sit in the open list once its checked copy stands in the Archive.

Each night, a check counts what stands open and what stands finished but still open. The morning dashboard shows that count in the Raven's Reach box.
